# PulsePoint
PulsePoint is a modern web application designed to help users track, analyze, and manage their health data in a simple and intuitive way. The platform allows seamless monitoring of vital signs, activity levels, and medical records, while providing insights to improve overall well-being.

# 🔑 Key Features

📊 Health Dashboard – View heart rate, blood pressure, and other vitals in real time.

🩺 Medical Records – Store and access important health history securely.

📅 Reminders & Alerts – Stay on top of medications and health checkups.

🔐 User Profiles – Personalized accounts with secure authentication.

🌐 Responsive Design – Optimized for desktop and mobile devices.
